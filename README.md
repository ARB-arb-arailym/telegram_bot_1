# 🚀 Productivity Telegram Bot

Telegram-бот для трекинга продуктивности и ежедневных задач. Бот помогает ставить большую цель и разбивать её на ежедневные шаги с отслеживанием прогресса до дедлайна (31 августа).

---

## 📌 Возможности

- Установка глобальной цели через /start  
- Автоматический дедлайн (31 августа текущего года)  
- Генерация 5–6 ежедневных задач через /tasks  
- Интерактивные inline-кнопки (выполнение задач)  
- Отслеживание общего прогресса через /progress  
- Сохранение данных в SQLite (ничего не теряется)  
- Локальная генерация задач без внешних API  

---

## ⚙️ Технологии

- Python 3.10+  
- aiogram v3  
- SQLite (sqlite3)  
- Telegram Bot API
